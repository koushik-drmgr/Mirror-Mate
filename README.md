# Mirror Mate -- Find Your Doppelgänger

**Mirror Mate** is a fun web platform where users can find their
*digital doppelgänger* and connect through classic games like **Chess,
Checkers, and Tic-Tac-Toe**. The site combines entertainment with the
concept of "mirror identities," making it interactive and engaging.

## 🚀 Features

-   🌐 Clean landing page with navigation (Home, Games, About)\
-   🎮 Built-in games: Chess, Checkers, Tic-Tac-Toe\
-   🤝 Concept of finding your *Internet Doppelgänger*\
-   📱 Responsive design with modern styling

## 🛠️ Tech Stack

-   **HTML5, CSS3, JavaScript** -- Frontend\
-   **Flask (Python)** -- Optional backend server for deployment\
-   **Google Fonts (Poppins)** for styling

## ▶️ How to Run

### Option 1: Open in Browser

Simply open `index.html` in your browser.

### Option 2: Run with Flask (Recommended)

1.  Install Flask:

    ``` bash
    pip install flask
    ```

2.  Run server:

    ``` bash
    python server.py
    ```

3.  Visit: `http://127.0.0.1:5000/`
